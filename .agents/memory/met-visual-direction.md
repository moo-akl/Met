name: Met visual direction
description: Approved Canopy × Apple direction and the boundaries of its app integration.
---

The user likes the Canopy — Olive and Apple-inspired explorations and wants a design mixing the two. The primary color should be like the app logo green, refining the earlier olive-only direction. Home must include some kind of recognizable geographical map; it may be expandable but must exist in the Home experience.

**Why:** After requesting olive-green alternatives with a Home map, the user selected Canopy and Apple-inspired as the preferred references and explicitly asked to combine them using the app logo green.

**How to apply:** The user selected Open Field Notes for Home and Profile and approved extending it to Connections and Events: use editorial open sections and thin dividers rather than card-heavy or map-first layouts. Event date sections should follow the selected language and device-local calendar day, align with RTL writing direction, be announced as screen-reader headings, and keep location-based nearby-first ordering primary when enabled. Event detail and attendee sections should use semantic headings and localized action labels; announce attendee names and check-in status separately from row actions so the actions remain reachable. Use real data and existing interactions; prototype-only actions must not become simulated production behavior. Keep a recognizable geographical map on Home, clear privacy language, and saved light/dark preferences.

Light Canopy is the default for users without a saved appearance choice; retain explicit light/dark preferences.

**Why:** The approved design uses warm paper and logo green, while existing users may have deliberately selected dark mode.

Avoid making every app page a stack of rectangular boxes. Mix asymmetric shapes, open layouts, and varied surface treatments while keeping screens clear and usable.

**Why:** The user said repeated rectangular boxes across pages make the app feel unpolished and asked for more varied, creative designs.

**How to apply:** When restyling Met screens, preserve the approved Canopy × Apple palette and recognizable components, but vary card silhouettes and use borderless or open layouts where they improve hierarchy.

Home's “A place to begin” should show the nearest venues first.

**Why:** The user explicitly requested proximity ordering rather than the server's default venue order.

**How to apply:** Sort the full venue collection using the device location before limiting the displayed cards; do not invent a location when permission is unavailable.
